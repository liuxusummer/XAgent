# Code Review Skill

Use this skill when the task is to review code, inspect a diff, or identify risks in an implementation.

## Method

- Prioritize bugs, behavioral regressions, missing tests, security issues, and maintainability risks.
- Report findings first, ordered by severity.
- Include file and line references when possible.
- Keep summaries brief and secondary to findings.
- If no findings are found, state that explicitly and mention residual risks or untested areas.

## Boundaries

- Do not rewrite code unless explicitly asked.
- Do not treat style-only preferences as findings unless they create real maintenance risk.
- Use existing project conventions as the baseline.
