# 记忆管理 SOP

## 更新类型判断

| 信号 | 操作 |
|------|------|
| 新发现关键信息 | 新增条目到对应主题段 |
| 已有信息需要修正 | 修改对应条目 |
| 信息已过时或冗余 | 删除对应条目 |
| 无实质变化 | 不更新 |

## 最小化更新原则

1. 只修改需要变更的部分，不重写整个文件
2. 使用 file_patch 而非 file_write 修改记忆文件
3. 每次结算最多修改 1-2 个主题段
4. 新增条目必须与现有条目不重复

## 格式规范

### global_mem.txt（L2 长期记忆）
- 按主题分段，每段以 `## 主题名` 开头
- 每段内条目以 `- ` 开头
- 条目简洁，单行不超过 80 字符
- 空行分隔不同主题段

### global_mem_insight.txt（L0 记忆洞察）
- 固定结构：核心身份 / 行为模式 / 当前状态
- 核心身份：不随对话变化
- 行为模式：极少变化
- 当前状态：每次结算时更新

## 结算流程

1. 读取 global_mem.txt 和 global_mem_insight.txt
2. 回顾当前对话中的关键发现和决策
3. 判断更新类型（新增/修改/删除/无变化）
4. 执行最小化更新
5. 更新 global_mem_insight.txt 的"当前状态"段
